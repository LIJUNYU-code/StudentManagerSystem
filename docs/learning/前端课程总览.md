> 定位：项目已经能用，这门课的目标是让你**看懂并亲手改自己的前端**。
> 教材就是你 `web/src` 下的真实代码——每一课都对着一个你已经天天在用的文件讲。
> 规则：一次一课，每课一个动手练习，改完我 review，通过才进下一课。

## 学习方法约定

1. **每课结构**：概念（通俗版）→ 看你项目里的哪几行 → 动手改 → 我检查 → 下一课。
2. **先读后写**：每课先让我带着读代码，再自己动手，不允许复制粘贴我给的答案。
3. **改坏了不慌**：`git diff` 能看改动，`git checkout -- 文件名` 能还原，vite 报错会直接写在浏览器页面上。
4. **进度记录**：每课完成把上表状态改成 ✅ 并注明日期。

## 第 0 课 · 一个页面是怎么跑起来的

### 四个角色

| 角色 | 文件 | 通俗理解 |
| --- | --- | --- |
| Vite 开发服务器 | （命令 `pnpm dev`，端口 5173） | 现场编译员：浏览器看不懂 `.vue`，你要哪个页面它现编译哪个；你保存文件它秒级把改动推给浏览器（热更新 HMR） |
| 唯一的 HTML | `index.html` | 整个网站只有一张网页，`body` 里就一个空 `<div id="app">`，所有界面都是 JS 后来「画」进去的——所以叫**单页应用（SPA）**，点菜单从不白屏刷新 |
| 入口脚本 | `src/main.js` | 三件事：创建应用 → 装插件（router、Pinia、Element Plus）→ 挂载到 `#app` |
| 路由出口 | `App.vue` 里的 `<router-view/>` | 一个「占位窗口」，显示什么由浏览器地址栏 URL 决定 |

### 登录到首页的完整旅程（把链条背下来）

```
LoginView 表单(v-model 收集账号密码)
  → stores/auth.js 的 login()
    → api/index.js 的 axios 发 POST /auth/login
      → vite proxy 转发到 http://localhost:8080（解决跨域）
        → 后端校验密码，返回 Result{code, message, data: token}
      → 拦截器剥壳取出 data，401 分支统一弹错
    → store 存 token + localStorage（刷新不丢）
  → router.push('/students') → URL 变 → 路由把 MainLayout 装进 <router-view>
    → MainLayout 的 <router-view> 再装进 StudentsView（嵌套路由）
```

### 第 0 课练习（5 分钟）

1. VS Code 打开 `web/src/layout/MainLayout.vue`，在 `<template>` 里找到侧边栏底部的署名文字（`sidebar-foot` 那一行），改成你想要的句子。
2. 保存，**不要刷新浏览器**，盯着左侧边栏——文字应立即变化。这就是热更新（HMR）。
3. 提交：`git add web/src && git commit -m "chore(web): 个性化署名"`。

**验收**：侧边栏显示新文字，且全程没按过 F5。

**思考题（第 1 课开头对答案）**：`.vue` 文件里 `<template>`、`<script setup>`、`<style scoped>` 三段各管什么？`scoped` 三个字是什么意思？
